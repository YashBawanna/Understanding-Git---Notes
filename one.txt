1.  git init -- it initialise .git folder, git init is the command that turns a normal folder into a Git repository.
It is usually the first Git command you run when starting a new project.

2.  git add . -- add all the files 
    git add one.txt -- add only one.txt file
    

3.  git commit -- git commit is the command used to save a snapshot of your project into Git history.
    It is one of the most important Git commands.    

    git commit -am "Updated API"  -- skips stagging for tracked files

    Working Directory
        ↓
        git add
        ↓
    Staging Area
        ↓
    git commit
        ↓
    Git Repository    

4.  git status --git status is a Git command used to check the current state of the repository.

                git status

    5. Git Log -- git log is used to view commit history of the repository.

    6. Git restore -- it helps to bring commited code back to stagging stage.

    7. Git diff -- difference btw untraked changes and staging area
    8. git log --stat -- git log --stat is used to view:

        commit history
        changed files in each commit
        number of insertions and deletions

        It gives a summarized view of what changed in every commit.

    9. git commit --amend --> use to commit change in the recent commit by replacing it 

    10. git restore --staged  --> used to convert staged file in untracked file

    11 git reset -
       
      soft - "Undo the commit, but keep everything ready to commit again."
      mixed - "Undo the commit and unstage the files, but keep the code."
      hard - "Go back completely and delete all local changes."
    
    12. git reflog - stores HEAD movement history
                    we can recover
                    deleted commits -
                    lost branch pointers
                    commits removed by reset
                    accidental checkout/reset mistakes

    13. git remote

        Connects local repository to online repository.
        Used with platforms like GitHub.
        Enables push, pull, and collaboration.                

    14. git push origin main

        Pushes local main branch to remote repository.
        Uploads commits to remote branch.
        Does not save upstream tracking.     

    15. git push -u origin main

        Pushes code and sets upstream tracking.
        Git remembers remote branch connection.
        Future pushes can use only git push.

    23. git merge
        git merge is used to combine changes from one branch into another branch.
